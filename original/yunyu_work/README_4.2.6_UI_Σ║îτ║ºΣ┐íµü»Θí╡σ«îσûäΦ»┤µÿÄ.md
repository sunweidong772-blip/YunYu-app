# 云屿 App 4.2.6 UI 二级信息页完善版

本次继续在 4.2.5 基础上进行视觉收口，重点处理容易被忽略但会影响整体产品成熟度的二级信息页面。

## 本次落地
- 新增 `Yunyu V25` 二级信息页视觉组件
- 新增 `YunyuInfoHero`：统一关于、协议、隐私等页面的品牌首屏
- 新增 `YunyuInfoSection`：统一长文本内容的阅读卡片与层级
- 升级关于云屿页面的品牌入口与版本信息展示
- 升级用户协议、隐私政策的阅读节奏，降低长文本页面的割裂感
- 保持原有页面内容、链接、路由与业务逻辑不变

## 视觉目标
让设置二级页不再是“普通系统页面”，而是完整延续云屿的云感、岛屿感与信息层级体系。
