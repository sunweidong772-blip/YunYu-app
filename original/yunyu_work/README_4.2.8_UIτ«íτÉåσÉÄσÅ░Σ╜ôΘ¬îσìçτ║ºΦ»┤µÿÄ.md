# 云屿 App 4.2.8 · UI 管理后台体验升级

本版本继续基于 4.2.7 源码进行视觉优化，不修改现有 API、数据模型、权限判断或审核业务流程。

## 本次重点
- 新增 Yunyu V27 管理后台视觉组件。
- 管理概览数据卡片统一信息密度、圆角和状态图标层级。
- 工作台入口统一为后台操作卡片，强化触控面积与待处理信息可读性。
- 为帖子审核、软件审核、用户管理、举报处理等页面后续统一提供复用组件基础。
- 保持浅色 / 深色主题兼容。

## 新增组件
- `YunyuAdminMetricCard`
- `YunyuAdminActionTile`
- `YunyuAdminNotice`

## 设计原则
后台仍属于“云屿”的同一座岛屿：强调效率，但不使用与前台割裂的传统后台视觉；保持清晰、克制、可快速扫描。
