# 云屿 App 4.2.2｜核心页面 UI 逐页落地版

本版本在 4.2.1 组件体系基础上，将视觉组件进一步实际落地到用户高频页面。

## 已处理页面
- 社区首页：内容流增加统一栏目标题与数据胶囊。
- 帖子详情：评论区域采用统一章节标题，强化阅读层级。
- 软件详情：软件介绍、版本历史、发布者统一章节语言。
- 个人主页：Hero 身份区加入 MY ISLAND 品牌层级。

## 新增组件
- `YunyuSectionHeader`：统一眉题、标题、副标题。
- `YunyuMetricPill`：统一浏览、点赞、评论等轻量数据展示。

## 原则
本轮只调整表现层，不修改接口、数据模型、路由或业务流程。
