# 云屿 App 4.2.1 UI 核心体验升级

本版本在 4.2.0 视觉体系基础上继续收口，目标是让后续核心页面可以复用同一套成熟组件，而不是继续零散修改颜色与圆角。

## 本次新增
- Yunyu V20 页面视觉规范
- 云雾背景容器 `YunyuCloudBackdropV20`
- 核心页面内容壳 `YunyuPageShell`
- 身份信息胶囊 `YunyuIdentityChip`
- 低干扰分隔组件 `YunyuSoftDivider`
- 统一 20dp 页面安全边距、26dp 内容容器圆角与 240ms 微动效节奏

## 优化原则
1. 不改变现有接口、数据结构与业务流程。
2. 不删除原有社区、软件、消息、个人中心与后台能力。
3. 新组件全部位于 `frontend/lib/core/`，后续可逐页接入。
4. 继续兼容浅色、深色与跟随系统主题。

## 下一轮接入优先级
社区信息流 → 帖子详情 → 软件详情 → 个人主页 → 消息中心 → 设置页 → 管理后台。
