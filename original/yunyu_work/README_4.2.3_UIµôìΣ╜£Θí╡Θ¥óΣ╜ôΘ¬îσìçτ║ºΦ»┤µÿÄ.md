# 云屿 App 4.2.3 UI 操作页面体验升级说明

本次版本重点处理高频操作页面的统一体验：消息中心、设置页与管理中心接入同一套页面引导与操作表面规范。

## 本次视觉升级
- 新增 `YunyuV22` 页面操作层视觉规范
- 新增 `YunyuPageIntro`：统一英文眉题、中文主标题与页面说明
- 新增 `YunyuActionSurface`：用于后续消息、发布、设置操作入口的统一点击表面
- 消息中心强化“消息岛 / 回声”品牌语言
- 设置页升级为“个人云空间”信息层级，并同步版本展示为 4.2.3
- 管理中心增加统一的页面引导区，减少后台页面与前台视觉割裂

## 保持不变
- 未修改接口、数据模型、数据库结构
- 未删除现有功能、路由和权限逻辑
- 本轮以视觉组件与页面层级优化为主

## 后续方向
下一阶段可继续把软件列表、软件发布表单、消息会话详情、设置二级页和管理后台卡片逐页迁移到 V22 组件体系。
