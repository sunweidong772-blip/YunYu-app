# 云屿 App 4.1.0 UI 视觉优化版

本包基于原始“云屿 App 完整源码”进行视觉层升级，原则是：**不重构后端、不删除现有功能、不改变接口与权限业务逻辑**，重点统一前端体验。

## 本次优化
- 全局视觉规范升级为 Yunyu V14 / 4.1.0
- 首页底部导航升级为圆角悬浮式岛屿导航，中央发布按钮更突出
- 启动初始化页增加云屿品牌加载体验
- 优化品牌蓝、背景留白、卡片层次、圆角与阴影
- 统一高频页面的 Hero、身份卡、等级/管理员徽章、空状态视觉
- 保留社区、软件、消息、个人中心、发布、管理后台等原有功能结构
- 保留浅色 / 深色 / 跟随系统主题能力

## 说明
建议使用 Flutter/Android Studio 打开 `frontend` 目录后执行依赖获取与构建。
本次版本定位为 **4.1.0 小版本 UI 视觉升级**。
