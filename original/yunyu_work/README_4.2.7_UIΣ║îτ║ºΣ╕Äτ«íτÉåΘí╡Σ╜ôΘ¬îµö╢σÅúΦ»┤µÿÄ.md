# 云屿 App 4.2.7 · UI 二级与管理页体验收口

本版继续基于 4.2.6 进行视觉收口，不改变接口、数据模型、权限与业务流程。

## 本次落地
- 新增 `YunyuDetailHero`：用于设置、资料编辑等二级页的统一品牌首屏。
- 新增 `YunyuSettingTile`：统一设置列表的图标、间距、触控区域与信息层级。
- 设置页升级为 V26 二级页视觉语言，并同步更新版本展示文案。
- 编辑资料页新增 MY ISLAND 品牌引导与成长信息章节，强化头像、身份与等级信息层级。
- 保留浅色/深色主题兼容，保留现有保存、头像上传、通知、缓存与退出登录逻辑。

## 后续建议
下一阶段继续处理管理后台各功能页面的筛选栏、数据卡片、空状态与批量操作反馈，形成前台与后台一致的云屿产品体验。
