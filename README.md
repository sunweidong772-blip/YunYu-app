- 已建立首页/社区、应用、消息入口、我的、登录入口、签到入口、管理后台入口

## 原后端接口（已核对）
包含认证、用户资料、帖子、评论、点赞、关注、私信、应用、收藏、举报、公告、徽章、头像框及完整管理员接口。

## 运行
### 后端
cd backend
npm install
配置 PostgreSQL 后执行 schema.sql
npm start

### Web
cd yunyu-web
npm install
npm run dev

默认后端地址：`http://localhost:3000`。可在“我的 → 后端连接设置”修改。
