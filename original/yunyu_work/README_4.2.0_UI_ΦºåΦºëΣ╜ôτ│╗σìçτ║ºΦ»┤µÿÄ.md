# 云屿 App 4.2.0 UI 视觉体系升级

本版本在 4.1.4 的全局收口基础上继续升级，核心目标是把此前分散在页面中的视觉做法沉淀为可复用的「云屿视觉层」。

## 本轮完成
- 新增 V19 视觉规范：统一页面留白、卡片、Hero 圆角、章节间距与底部安全区。
- 新增 `YunyuCloudBackdrop`：为主页面提供轻量云雾背景层，并自动适配深色模式。
- 新增 `YunyuSectionHeader`：用于后续社区、软件、消息和个人中心统一章节标题样式。
- 首页主容器接入 V19 云雾背景，不修改原有导航、页面切换和发布逻辑。
- 启动页接入同一套云雾背景，强化「云屿」品牌识别。

## 设计原则
1. 云感只作为背景层，不抢内容。
2. 信息流、详情、表单优先保证阅读效率。
3. 品牌色集中在关键操作和选中状态。
4. 保留现有业务逻辑、接口与路由结构。

## 后续页面落地顺序
社区首页与帖子详情 → 软件详情与软件发布 → 个人主页 → 消息中心 → 设置与管理后台。
