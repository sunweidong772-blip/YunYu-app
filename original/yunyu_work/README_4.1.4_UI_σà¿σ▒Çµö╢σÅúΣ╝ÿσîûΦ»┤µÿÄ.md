# 云屿 App 4.1.4 UI 全局收口优化说明

本版本定位：在 4.1.3 核心页面视觉精修基础上进行一次「全局收口」，重点不是继续堆叠视觉效果，而是统一成熟产品的细节。

## 本次完成
- 新增 Yunyu V18 全局视觉规范，统一页面留白、导航尺寸、卡片圆角与微动效节奏。
- 首页底部导航改为更紧凑的悬浮岛屿比例，降低边框存在感。
- 选中状态胶囊、图标与文字间距重新校准，提升可读性。
- 中央发布按钮统一为 V18 行为尺寸，与底部导航比例更协调。
- 保留现有功能入口、路由、登录判断和发布逻辑，不新增虚构功能。

## 本轮原则
1. 视觉优先，但不破坏业务逻辑。
2. 保持「云、屿、社区」品牌方向，不做通用模板化界面。
3. 后续页面继续复用统一设计 token，避免每页单独写一套样式。

云屿 App 4.1.4 · UI 全局收口优化版
