# 云屿 App 4.1.3 核心页面视觉精修说明

## 本次定位
4.1.3 不改变云屿既有业务结构，继续以「云间相遇，岛上交流」为视觉主线，对核心页面的阅读、身份与操作层级进行统一。

## 本轮重点
- 统一社区内容的阅读节奏：标题、正文、数据与身份信息形成明确层级。
- 统一帖子详情、软件详情的详情页信息密度，优先保证内容可读性。
- 统一个人主页、消息中心、设置页的分组节奏，减少零散卡片感。
- 管理后台继续保持高信息密度，同时沿用云屿品牌色作为强调而非大面积装饰。
- 新增 V17 尺寸规范，为后续页面逐页精修提供统一基准。

## 设计原则
1. 功能优先：不新增虚假的入口，不删除现有业务能力。
2. 云感克制：品牌色用于导航、重点状态与核心操作。
3. 内容优先：社区和详情页减少无意义装饰，提升阅读效率。
4. 身份可见：等级、管理员头衔与用户信息保持稳定层级。
5. 统一反馈：按钮、卡片、圆角、间距和页面安全区遵循同一套规范。

## 后续方向
后续版本将继续针对实际页面组件逐个精修，并在具备 Flutter 编译环境后进行完整静态检查与真机视觉验收。
