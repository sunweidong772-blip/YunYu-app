# 云屿 App 4.2.4｜UI 高频操作页逐页完善说明

## 本版定位
4.2.4 是 4.2.x 视觉体系的继续落地版本，重点收口用户高频进入和高频操作的页面，而不是改动后端接口、数据模型或权限逻辑。

## 本轮方向
- 软件浏览页：强化“发现好软件”的内容入口感
- 私聊页：统一会话顶部身份层级与输入区域的操作面
- 软件发布：后续表单可直接复用 V23 操作面组件
- 设置二级页与管理后台：统一使用 V23 的卡片圆角、边框和点击反馈规范

## 新增组件
`lib/core/yunyu_v23_visual.dart`
- `YunyuSoftSurface`：统一的柔和操作卡片/输入承载面
- `YunyuCompactAction`：图标 + 文案的紧凑操作入口

## 设计原则
1. 不修改 API、路由和数据字段
2. 不删除已有功能
3. 浅色、深色模式保持兼容
4. 组件优先复用，减少每个页面各自定义样式

版本号：4.2.4
