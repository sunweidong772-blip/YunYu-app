# 云屿 App 4.2.5 UI 表单与二级页完善说明

本版本继续在 4.2.4 基础上进行高频操作体验收口，保持原有接口、数据模型与业务流程不变。

## 本轮落地
- 新增 `Yunyu V24` 表单与二级页面视觉规范。
- 新增 `YunyuFormHeader`：用于发布、编辑等任务型页面的品牌引导区。
- 新增 `YunyuFormStep`：为多步骤表单保留统一的可复用信息层级。
- 软件发布页接入新的云屿任务型页面视觉：品牌引导 + 清晰的发布资料层级。
- 延续 V19-V23 的云雾、圆角、卡片与浅深色兼容体系。

## 兼容原则
- 不修改 API 地址与请求字段。
- 不修改数据模型、权限与审核流程。
- 不删除现有发布、上传、图标上传与错误反馈逻辑。

## 后续建议
下一轮可继续把编辑资料、隐私政策、用户协议、关于云屿等二级页面统一到 V24 页面容器体系，并对管理后台卡片密度进行最终收口。
